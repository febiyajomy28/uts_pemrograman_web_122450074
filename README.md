# ✨ Celesté Scents

**Celesté Scents** adalah website e-commerce yang berfokus pada produk **beauty dan personal care**. Website ini dikembangkan sebagai proyek Ujian Tengah Semester (UTS) mata kuliah Pemrograman Web dengan menggunakan **React.js** dan **Vite**.

Website ini menyediakan pengalaman berbelanja produk beauty secara sederhana dan interaktif, mulai dari melihat daftar produk, melihat detail produk, melakukan autentikasi pengguna, hingga proses checkout.

## 🌸 Features

* 🏠 **Home Page**
  Menampilkan halaman utama dan informasi produk beauty.

* 💄 **Beauty Product List**
  Menampilkan berbagai produk beauty menggunakan data dummy JSON.

* 🔍 **Product Detail**
  Menampilkan informasi detail dari produk yang dipilih.

* 🔐 **Login & Sign Up**
  Menyediakan fitur autentikasi untuk pengguna.

* 🛒 **Checkout**
  Menyediakan halaman untuk proses checkout produk.

* ⭐ **Review**
  Pengguna dapat melihat dan memberikan ulasan terhadap produk.

* ❓ **FAQ**
  Menyediakan informasi pertanyaan yang sering ditanyakan pengguna.

* 📦 **Secure Stock**
  Menampilkan informasi terkait ketersediaan produk.

* 🔒 **Private Route**
  Beberapa halaman dilindungi dan hanya dapat diakses oleh pengguna yang telah melakukan login.

* 📱 **Responsive Interface**
  Tampilan website dirancang agar dapat digunakan pada berbagai ukuran layar.

## 🚀 Installation

Pastikan **Node.js** dan **npm** sudah terinstall pada komputer.

### 1. Clone repository

```bash
git clone https://github.com/febiyajomy28/uts_pemrograman_web_122450074.git
```

### 2. Masuk ke folder project

```bash
cd uts_pemrograman_web_122450074
```

### 3. Install dependencies

```bash
npm install
```

### 4. Jalankan project

```bash
npm run dev
```

Kemudian buka alamat localhost yang diberikan oleh Vite pada browser.

## 📜 Available Scripts

Menjalankan development server:

```bash
npm run dev
```

Melakukan build untuk production:

```bash
npm run build
```

Menjalankan ESLint:

